LingoDrill

Learn a language by ear: cut a recording into short fragments and drill each one — on repeat, slowed down, with its subtitles.

Android This device

Chrome, Edge, Samsung Internet or Firefox

  1. Open LingoDrill in Chrome.
  2. Tap Install when the browser offers it, or open the menu and tap Install app (Add to Home screen in older versions), then confirm.
  3. Start LingoDrill from its icon on the home screen or in the app list.

Samsung Internet: ☰ menu → Add page to → Home screen. Edge: menu → Add to phone. Firefox: ⋮ menu → Add to Home screen.

iPhone and iPad This device

Safari — or Chrome and Edge on iOS 16.4 and newer

  1. Open LingoDrill in Safari.
  2. Tap Share in the toolbar. On iOS 26 tap next to the address first.
  3. Tap Add to Home Screen — scroll down or tap More if it is not in the list. Leave Open as Web App on if it is shown, then tap Add.
  4. Start LingoDrill from its icon on the home screen.

Install first, then add your audio: the installed app does not see files you added in a Safari tab.

Computer This device

Windows, macOS, Linux or ChromeOS — Chrome or Edge

  1. Open LingoDrill in Chrome or Edge.
  2. Click the Install icon at the right end of the address bar, then Install.
  3. LingoDrill opens in its own window. Start it later from the Start menu, the Dock or the app launcher.

Safari on a Mac: File → Add to Dock. Firefox cannot install web apps — LingoDrill works in an ordinary tab there.

  • Free, no account, no app store.
  • Works offline once it has been opened.
  • Your audio stays on your device — nothing is uploaded.
  • Updates itself: a new version is used the next time you open it.

Open the app

Open LingoDrill in your browser, then install it with the steps for your device.
